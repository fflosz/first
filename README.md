# Интерактивная карта

Пример простого проекта на основе [Leaflet](https://leafletjs.com/). Карта загружает точки из `markers.json`, а в боковой панели отображается RSS-лента новостей. Данные для карты можно редактировать вручную, изменяя JSON-файл.

## Файлы
- `map.html` — страница с картой и блоком новостей.
- `map.js` — логика инициализации карты и фильтрации маркеров по дате.
- `markers.json` — пример данных точек (координаты, дата и всплывающие подсказки).
- `rss.js` — простой загрузчик RSS-ленты.

Статический проект можно разместить, например, на GitHub Pages.
